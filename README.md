### 👨‍💻 Engineering Focus

As a Software Engineer focusing on Backend Architecture and Full-Stack Development, I specialize in translating complex geospatial and agricultural data into interactive, actionable platforms.

- 🌍 **Current Focus:** Building robust Web-GIS platforms (like KrishiZest) utilizing React.js, FastAPI, and OpenLayers.
- ⚙️ **Architecture:** Designing scalable backend systems and optimizing PostgreSQL/PostGIS databases to reduce query execution time for heavy spatial datasets.
- 🤖 **AI Integration:** Leveraging LLMs (OpenAI) for dynamic data analysis and automated stakeholder reporting.
- ☁️ **Infrastructure Roadmap:** Actively planning the transition to containerized deployments mastering AWS, Docker, and Kubernetes for production-grade scaling.
